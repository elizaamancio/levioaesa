Este projeto explora a interseção entre pole sport, coreografia e inteligência artificial.

O principal objetivo é desenvolver um sistema de coreografia assistida por IA capaz de:

- Gerar e organizar sequências de movimentos de pole sport
- Compreender transições entre elementos
- Apoiar a criatividade e o treinamento de atletas
- Auxiliar na preparação para competições
- Criar uma base de dados estruturada de movimentos e características técnicas do pole sport

O projeto está sendo desenvolvido em paralelo ao treinamento prático e à experiência em competições de pole sport, incluindo preparação para campeonatos ligados ao movimento de reconhecimento olímpico da modalidade.
